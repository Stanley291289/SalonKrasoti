# SalonKrasoti
Конфигурация автоматизирует оперативный и бухгалтерский учёт салона красоты: запись клиентов, продажи услуг и товаров, учёт денежных средств, расчёт себестоимости, отчёты.   Ключевая особенность – **интеграция с мобильным приложением** для самостоятельной записи клиентов через смартфон.
