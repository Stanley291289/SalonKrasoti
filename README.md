# 💇‍♀️ 1С:Салон красоты – учётная система с интеграцией мобильного приложения

**Дипломный проект.** Конфигурация автоматизирует оперативный и бухгалтерский учёт салона красоты: запись клиентов, продажи услуг и товаров, учёт денежных средств, расчёт себестоимости, отчёты.  
Ключевая особенность – **интеграция с мобильным приложением** для самостоятельной записи клиентов через смартфон.

> ✅ Внедрены подсистемы **БСП** (Базовая функциональность, Организации, Печать, Дополнительные отчёты и обработки).  
> ✅ Разработана **внешняя печатная форма** «Товарная накладная».  
> ✅ Реализована **загрузка прайс-листа из Excel** в регистр цен.  
> ✅ Настроен **обмен с мобильной конфигурацией** через HTTP-сервисы.

## 📌 Основные возможности

### 🧾 Оперативный учёт
- Справочники: Номенклатура (товары/услуги), Контрагенты, Сотрудники, Должности, Организации, Договоры, Кассы, Склады, Статьи затрат, Источники информации.
- Документы:
  - **Поступление товаров и услуг** (приход ТМЦ и услуг).
  - **Предварительная запись** клиента.
  - **Реализация** (вводится на основании записи, автоматически заполняет организацию, контрагента, сотрудника, сумму).
  - **Приходный / Расходный кассовый ордер** (вводятся на основании реализации или поступления).
- Регистры накопления:
  - **Товары на складах** (остатки, контроль отрицательных остатков, списание по средней).
  - **Заказы клиентов** (контроль исполнения записей).
  - **Продажи** (обороты выручки в разрезе сотрудников, клиентов, услуг).
  - **Учёт затрат** (накопление расходов, списание себестоимости товаров).
  - **Денежные средства** (остатки наличных в кассах).

### 📊 Аналитические отчёты
- **Товары на складах** – остатки, приход, расход (с отборами по организации, складу, номенклатуре).
- **Продажи** – выручка по мастерам, клиентам, услугам (только услуги, сортировка по сумме).
- **Финансовый результат** – доходы минус расходы (прибыль/убыток с цветовым выделением).
- **Движение наличных денег** – остатки и обороты по кассам.

### 📚 Бухгалтерский учёт (вторая часть проекта)
- План счетов «Хозрасчётный» (с предопределёнными счетами 10, 41, 44, 50, 51, 60, 62, 70, 90, 91).
- Регистр бухгалтерии «Хозрасчётный» (корреспонденция счетов).
- Автоматическое формирование проводок по документам:
  - Поступление товаров и услуг (Дт 10/41 – Кт 60).
  - Реализация (выручка Дт 90 – Кт 90.01, себестоимость Дт 90.02 – Кт 41/44).
  - Приходный кассовый ордер (Дт 50 – Кт 62/60).
  - Расходный кассовый ордер (Дт 60/71 – Кт 50).
- **Оборотно-сальдовая ведомость по счёту** (с детализацией по субконто).
- **Журнал хозяйственных операций**.

### 🔌 Интеграция с мобильным приложением
- Мобильная конфигурация позволяет клиентам **самостоятельно записываться на услуги**.
- Авторизация через логин (проверка в основной базе по реквизиту «ПользовательМП» справочника Контрагенты).
- Отправка документа **«Запись клиента»** из мобильного приложения в основную базу через HTTP-сервис.
- В мобильном приложении – справочники «Услуги» и «Сотрудники», форма записи, список «Мои записи».

### 📎 Внешняя печатная форма и загрузка из Excel
- **Внешняя печатная форма «Товарная накладная»** для документа «Реализация» (подключается через БСП).
- **Загрузка прайс-листа из Excel** (xlsx) в регистр сведений «Цены номенклатуры».  
  Формат файла: № п/п | Наименование | Код номенклатуры | Цена.

### ⚙️ Библиотека стандартных подсистем (БСП)
Внедрены и настроены:
- Базовая функциональность, Обновление версий ИБ, Пользователи.
- Организации (определяемый тип), Печать, Дополнительные отчёты и обработки.
- В коде используются методы `СообщитьПользователю`, `ЗначениеРеквизитаОбъекта`.

## 🚀 Установка и запуск

### Требования
- Платформа 1С:Предприятие 8.3 (не ниже 8.3.20).
- Режим совместимости – «Управляемые формы».

### Инструкция (основная конфигурация)
1. Скачайте файл конфигурации (`.cf` или `.dt`) по ссылке ниже.
2. Создайте новую информационную базу.
3. Загрузите конфигурацию через «Конфигуратор» → «Загрузить конфигурацию из файла» (для `.dt` – «Администрирование» → «Загрузить информационную базу»).
4. Запустите базу в режиме «1С:Предприятие».
5. При необходимости заполните справочники (организации, кассы, склады, сотрудников).

### Мобильная конфигурация (опционально)
1. Отдельный файл выгрузки `.dt` для мобильного приложения.
2. Разворачивается на платформе 1С:Предприятие для мобильных устройств (или в учебном режиме на ПК).
3. В основной базе должен быть настроен HTTP-сервис (порт и адрес).
